# Instant AI — MT-33-H

This repository contains the work for the Instant AI MT-33-H program. Tasks 1–4 are hosted as Google Colab notebooks; this repository stores their links and the local Python exercises from Task 1.

## Structure

| File | Description |
|---|---|
| `task_1_colab.txt` | Link to the Task 1 Colab notebook |
| `task_2_colab.txt` | Link to the Task 2 Colab notebook |
| `task_3_colab.txt` | Link to the Task 3 Colab notebook |
| `task_4_colab.txt` | Link to the Task 4 Colab notebook |
| `task_1.py` | Local Python exercises: triangle area, swapping variables, km-to-miles conversion |
| `task_1_assignment.pdf` / `task_1_assignment.docx` | Original Task 1 assignment sheet |

## Requirements

No third-party packages are required for `task_1.py`. Any modern Python 3 version works.

## Run locally

```bash
python task_1.py
```

The script asks for:

1. Triangle base and height → prints the area.
2. Two integers → prints them before and after swapping.
3. Distance in kilometers → prints the equivalent miles.

## Colab notebooks

Open the URL inside any `task_*_colab.txt` file to run the corresponding notebook.
